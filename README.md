## 常见问题

**日本VPS年付多少钱算正常？**
国际线路入门款 $13—45/年（约95—330元），国内优化线路主流100—300元/年，原生IP和住宅IP从500元/年起。明显低于这些价位的，要么是限时秒杀，要么配置和流量有阉割，下单前逐项看清。

**为什么日本VPS比美国VPS贵？**
日本本地带宽资源贵。30Mbps、50Mbps小水管很常见，能到300Mbps以上就算大方。加上距离中国近、线路分档多（软银、IIJ、CN2、普通国际），同样的钱在日本能买到的带宽通常比美国少。

**软银、IIJ、CN2、三网直连有什么区别？**
都是回程路由的走法。软银和IIJ是日本本地运营商，对移动方向和国际互联比较友好；CN2是电信的优化骨干；三网直连指电信、联通、移动各自走优化回程。没有哪种全场景最强，取决于你自己的运营商。

**年付还是月付？**
有周期门槛的折扣（比如 hostdare 半年付起才享7折）只有年付拿得到；对线路没把握就先月付，实测延迟和解锁没问题再锁年付。年付的真正价值是锁价，顺便免掉月付的溢价。
